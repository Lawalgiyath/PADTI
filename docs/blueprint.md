# **App Name**: PADTI Connect

## Core Features:

- User Authentication & Authorization: Secure sign-up, login, and role-based access for students, employers, and administrators, utilizing Firebase Authentication.
- Dynamic Marketing Website: Engaging homepage sections (Hero, Programs, Success Stories, etc.) built to showcase PADTI, with responsive layouts and WCAG compliance for broad accessibility.
- Admissions Portal: Student registration, application submission with document upload via Firebase Storage, eligibility screening, and status tracking for applicants, all managed through Firestore.
- Learning Portal (MVP): Students can access enrolled courses, track their progress, view basic assessments, and obtain certificates, with course data managed in Firestore.
- AI Study Assistant Tool: An AI tool provides personalized study recommendations based on student progress and assessment results, helping optimize their learning path.
- Job & Internship Marketplace: Students can browse and apply for internship and job opportunities posted by industry partners, with all data stored in Firestore.
- Employer & Recruiter Portal: Employers can register, post job/internship opportunities, manage listings, and verify candidate certifications and driver status, with data persisting in Firestore.

## Style Guidelines:

- Light Color Scheme - Primary color: A deep, authoritative blue (#285BBD) for branding and interactive elements, conveying trust and professionalism.
- Background color: A subtle, desaturated cool grey-blue (#E8EAEE), providing a clean and understated canvas for content.
- Accent color: A bright, distinct cyan (#2BEDEE) to highlight key actions, call-to-action buttons, and interactive feedback, ensuring good contrast.
- Full support for light and dark modes will be implemented across all color specifications, adapting seamlessly to user preference.
- Headline and body font: 'Inter' (sans-serif) for its modern, clean, and highly readable qualities, fitting an enterprise-grade platform.
- Clean, line-based vector icons consistent with ShadCN UI standards will be used to maintain a professional and accessible interface.
- Mobile-first responsive layouts, adhering to a structured grid system to ensure visual consistency and optimal readability across all device sizes. Clear visual hierarchy to guide user interaction.
- Subtle, functional animations and transitions, utilized primarily for feedback on user interactions and state changes to enhance perceived performance without distraction.
